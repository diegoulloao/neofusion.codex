# 1. Prerequisites 📦

- [Codex CLI](https://github.com/openai/codex) installed
- Latest Codex version recommended

---

# 2. Installation ⚡️

Create the themes directory if it does not exist:

```bash
mkdir -p ~/.codex/themes
```

Copy the theme file into the directory:

```bash
cp neofusion.tmTheme ~/.codex/themes/
```

---

# 3. Basic usage ✨

## A. Temporary (inside Codex)

Inside Codex, run:

```text
/theme
```

Then select:

```text
neofusion
```

---

## B. Set as default

Edit your Codex config file:

```bash
~/.codex/config.toml
```

Add:

```toml
[tui]
theme = "neofusion"
```

Restart Codex.

> Codex uses custom themes for syntax highlighting. Interface colors continue to respect your terminal palette.
